# ALIVE: Last Stand
A post-apocalyptic zombie survival mod for Quake 4.

## Description
ALIVE: Last Stand transforms Quake 4 into a zombie survival 
experience. Enemies behave like zombies, weapons are 
overhauled for post-apocalyptic survival, and the last 
uninfected player standing wins.

## How to Launch
Run the included shortcut or launch Quake 4 with:
+set fs_game alive

## Weapons Modified
- Blaster: Shotgun spread (5 projectiles)
- Rocket Launcher: Fires 5 rockets with spread
